# Usage

## Installation

1. Download the latest release
2. Extract the archive using password `2026`
3. Run the manager as Administrator
4. Launch FC 27
5. Select your mods and profiles

## Mods

1. Open the **Mods** tab
2. Click **Install Mod** to add a mod
3. Use **Mod Detection** to auto-detect mods
4. Sort mods by priority
5. Organize mods by category

## Profiles

1. Open the **Profiles** tab
2. Click **Save** to store current mod setup
3. Click **Load** to restore a profile
4. Use **Export** to share profiles
5. Use **Import** to load profiles from others

## Updates

1. Open the **Updates** tab
2. Click **Check for Updates** to find mod updates
3. Enable **Auto Update** for automatic updates
4. View **Update History** if needed
5. Use **Rollback** to revert changes

## Conflicts

1. Open the **Conflicts** tab
2. Click **Detect Conflicts** to find issues
3. Use **Conflict Resolution** to fix issues
4. Adjust **Load Order** if needed
5. Run **Dependency Check** for mod dependencies

## Backup

1. Open the **Backup** tab
2. Click **Backup** to save game files
3. Click **Restore** to restore from backup
4. Enable **Auto Backup** for automatic backups
5. Use **Backup Manager** to manage all backups

## Config

1. Open the **Config** tab
2. Click **Save** to store current settings
3. Click **Load** to restore a profile
4. Enable **Dark Mode** for dark theme
